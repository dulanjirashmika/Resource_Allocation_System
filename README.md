# Resource_Allocation_System
This Hotel Booking System is an efficient resource allocation tool focused on managing hall reservations and customer records. Users can register customers, search or delete records, and manage hall information such as hall number, capacity, and daily charge. The system also supports registering new halls to keep the database up to date.

Halls can be booked for a continuous period (e.g., from July 1 to July 5) or for specific dates (e.g., every Sunday in a month). The system calculates total payments based on the duration and daily rate.

Data is stored in a MySQL database, and the application is built with Java using JDBC for database connectivity. It's a reliable and user-friendly system ideal for managing hotel or event hall bookings with accuracy and ease.
